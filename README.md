# Cyber Detective — Projeto completo

Este pacote contém os arquivos completos da versão mais recente do projeto:

- `index.html` — estrutura principal do jogo;
- `style.css` — estilos do jogo;
- `auth-styles.css` — estilos da tela de autenticação;
- `auth.js` — tela inicial, login, cadastro e integração Supabase;
- `app.js` — lógica dos casos, pistas, decisões, XP, conquistas, diário e terminal;
- `sound.js` — som ambiente e efeitos de clique;
- `supabase_setup.sql` — estrutura inicial do banco de dados;
- `README.md` — instruções do projeto.

## Instalação

1. Extraia todos os arquivos na mesma pasta.
2. Publique todos os arquivos no repositório do jogo.
3. Mantenha os nomes dos arquivos exatamente como estão.
4. Aguarde o deploy do Render.

## Observação

Faça um backup da versão atual antes de substituir os arquivos. As configurações do Supabase ficam no `auth.js` e o banco pode ser preparado com o `supabase_setup.sql`.
