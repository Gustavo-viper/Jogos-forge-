# Cyber Detective — Projeto completo atualizado

Esta versão preserva a estrutura original do jogo e integra as atualizações solicitadas:

- Remove o menu lateral duplicado da tela inicial;
- Remove a opção Ranking da tela inicial;
- Mantém apenas Início, Sobre, Casos e Ajuda no menu inicial;
- Abas Sobre, Casos e Ajuda abrem janelas flutuantes;
- Inclui história da Forge Studios, criada por um casal gaúcho, e origem do Cyber Detective;
- Lista os 7 casos disponíveis;
- Acrescenta pistas extras aos dossiês;
- Ao concluir um caso, mostra se o jogador acertou ou errou e exibe a resposta correta;
- Mantém login/Supabase e os arquivos originais do jogo;
- Adiciona controles para som de suspense na tela inicial e preserva o áudio do jogo.

## Instalação
1. Faça backup do projeto atual.
2. Substitua os arquivos pelos desta pasta.
3. Preserve as credenciais e políticas do Supabase.
4. Publique no GitHub e aguarde o deploy do Render.

## Observação
Os contatos exibidos em Ajuda podem ser alterados diretamente no `auth.js`.
