# Cyber Detective — Edição Investigação Real v3.0

Jogo de investigação digital fictícia desenvolvido em HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` em um navegador.
3. Não é necessário servidor, login, Supabase ou internet para jogar.

## Recursos
- 7 casos com progressão de campanha.
- Quadro de evidências.
- Entrevistas com suspeitos.
- Dispositivo fictício explorável em cada caso.
- Diário automático.
- Terminal de investigação.
- XP, níveis e conquistas.
- Decisões finais e relatórios.
- Salvamento local no navegador.
- Tema claro/escuro.
- Interface responsiva para celular e computador.

Todos os elementos de investigação são fictícios e fazem parte da narrativa do jogo.
